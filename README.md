# Raspagem-da-Folha-de-S.-Paulo

Esse repositório serve para organizar o script utilizado para a raspagem das notícias da Folha de S. Paulo utilizados na minha iniciação científica intitulada "A produção de opinião política entre os acadêmicos: Um estudo sobre intervenção pública dos docentes universitários no ano eleitoral de 2022", sob orientação do Prof. Edison Bertoncelo.

Os dados coletados nessa raspagem dizem respeito aos artigos de opinião da Folha de S. Paulo que foram escritos durante e sobre o ano eleitoral de 2022 e que possuem autoria identificada.

**Importante**

Ressalto que os códigos publicados nesse repositório **não foram da minha autoria**. Os códigos foram disponibilizados pelo usuário do GitHub "bdcdo" com aprimoramento do Claude Sonnet 5.5, da Anthropic.
